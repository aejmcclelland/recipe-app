### 1. Mobile imported-recipe toolbar
- Floating toolbar obscures import-page content/actions.
- Oversized on mobile.
- Positioning is poor once a scraped recipe preview appears.
- Review whether all PDF/print/reset/save actions even belong in that form on mobile.
- Fix as part of the upcoming editable import/review UX, rather than patching its position tonight.
### 2. Unauthenticated import error
- Importing while logged out produces a misleading clipboard-related/general failure rather than something like “Sign in to import this recipe.”
- We need to distinguish clipboard errors, authentication errors, unsupported recipe URLs and scraper/import failures instead of collapsing them into a generic failure state.
